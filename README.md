# Factory Overlord — Launch UI

This version is the commercial gameplay direction: a live factory floor, one clear upgrade action, ownership-based progression, factory portfolio, contracts, rank ladder and offline production.

Factory progression: Metal → Lumber → Diamond → Steel → Oil → Automotive → Electronics → Aerospace → Pharma → Media → Logistics → Global Industrial Empire.

The web build is a playable prototype. Before monetized release, connect production analytics, rewarded ads, purchases, privacy/consent, and final store assets.
