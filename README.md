# Factory Overlord — Live Factory Web MVP

This version is a mobile-first playable prototype with:
- animated factory floor
- moving conveyor products
- animated workers and machinery
- live production rates
- machine tap-to-manage interactions
- upgrades and worker hiring
- offline earnings
- 2x production boost
- prestige progression
- localStorage persistence

## GitHub Pages
Upload the contents of this `web` folder to the repository root (or deploy the folder with your preferred static host).

For GitHub Pages: Settings → Pages → Deploy from branch → `main` → `/ (root)` if the web files are at the repository root.

The Android project remains in the repository for EAS APK/AAB builds.
